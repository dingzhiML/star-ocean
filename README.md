# 我们的星海 ✨

我们两个人的家庭回忆相册：每张照片是一颗发光的星辰，按年份/地点/事件聚成星团，所有星团融成一颗随照片增长的球体星海。

- 线上地址：https://dingzhiml.github.io/star-ocean/
- 访问方式：输入家庭暗号（gate.js 第 8 行可修改）
- 技术：three.js + 3d-force-graph，纯静态站点，无后端

## 功能

- 3D 球体星海 · 昼夜双主题（自动跟随时间）· 时间线穿梭 · 全屏搜索
- 星团聚焦模式（其他星团变暗，星团定位到屏幕右侧）
- 照片灯箱放大 · 家庭暗号门锁 · 5 首背景音乐
- 手机 / 电脑 / 横屏全适配

## 更新方式

修改 index.html / app.js / styles*.css / gate.js / data/sample-photos.js / photos/ 后上传替换即可（版本号 ?v= 需递增以避开缓存）。
